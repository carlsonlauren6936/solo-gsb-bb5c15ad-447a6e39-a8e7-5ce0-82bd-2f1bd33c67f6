# 骑马钉小册子拼版检查工具

一个用于检查骑马钉（Saddle-Stitch）小册子拼版的 Web 应用。支持**单帖**与**分帖**两种模式：输入成品页数后自动补齐至 4 的倍数，生成每张纸正反两面的左右页码与空白版位，并按装订后的嵌套顺序预览（分帖模式按帖分组）。支持交换 / 编辑任意版位，实时校验重复页、缺页、同张纸正反配对异常与跨帖页码连续性，校验通过后可导出 CSV 或**下载双面打样**（独立 HTML：A4 横向、每张纸正反各一页、按短边翻转镜像排布，标出左右页码、空白版位、中央折线与四角对位标；启用爬移补偿时仅页码内容随补偿平移）。校验不通过时可**生成修复方案**：以服务端标准拼版为目标，按顺序列出交换 / 改值步骤（含版位、原值、目标值）并可一键应用。可选**骑马钉爬移补偿**：按单张纸厚度与补偿上限逐张计算补偿量，左版向右、右版向左（朝折线）移动，并在纸张卡片上显示方向与毫米值。

技术栈：Node.js + Express + 原生 HTML/CSS/JavaScript（无前端框架、无构建步骤）。

## 快速开始（Docker）

```bash
docker compose up --build
```

启动后在浏览器打开 **<http://localhost:3000>** 即可使用。

也可以直接用 Docker 命令：

```bash
docker build -t saddle-stitch-imposition .
docker run --rm -p 3000:3000 saddle-stitch-imposition
# 访问 http://localhost:3000
```

## 本地开发

```bash
npm install
npm start        # http://localhost:3000
npm test         # 运行拼版逻辑单元测试
```

## 功能

- **两种拼版模式**：
  - **单帖**：全部成品页补齐到 4 的倍数后作为一帖拼版（原有行为，默认模式）。
  - **分帖**：设置「每帖最多纸张数」M（1～8），每帖容量为 4M 个成品页；生成时按成品页顺序切成容量 4M 的连续区间，每个区间独立按骑马钉拼版，**仅最后一帖**把剩余页补空白至 4 的倍数。
- **自动补齐**：成品页数自动补齐为 4 的倍数，补出的页以「空白」版位呈现。
- **嵌套顺序预览**：纸张按装订后的套叠顺序排列，第 1 张为最外层，逐张向内（缩进示意）；分帖模式下按帖分组展示，组内缩进按帖内纸张序号计算，末帖标注「补空白」。
- **版位交换**：交换模式下依次点击任意两个版位即可交换其页码（可跨帖交换，校验会报跨帖异常）。
- **版位编辑**：编辑模式下点击版位可直接输入页码或设为空白。
- **实时校验**：
  - 重复页：同一有内容页出现多次；
  - 缺页：有内容页未出现在任何版位；
  - 同张正反配对异常：空白错位、左版应为偶数页 / 右版应为奇数页、每面左右页码之和应为本帖起止页之和、正面左↔反面右（及正面右↔反面左）应同属一张书叶（连续页）、纸张页码组合与帖内套帖顺序不符；
  - 跨帖连续性（仅分帖模式）：每帖版位必须落在本帖连续页区间，跨帖错放即报错。
  - 错误均定位到**纸张与版位**；分帖模式额外定位到**帖**。
- **错误禁止导出**：存在任何错误时「导出 CSV」与「下载打样」按钮禁用，服务端导出接口同样会拒绝。
- **修复方案**：校验不通过时可点击「生成修复方案」，服务端以标准拼版为目标，列出需修复的版位并给出按顺序执行的步骤——目标页有唯一来源（恰好出现一次）时优先**交换**归位（交换环按帖号 → 帖内纸张序号 → 面 → 版位的固定顺序拆解），缺页、重复页、越界页与空白错位则用**改值**补齐；每步展示版位、原值与目标值，可「一键应用」；生成方案后若又改动拼版，应用时会被拒绝并提示重新生成；修复保留分帖结构与爬移参数，既有 CSV 与打样导出继续可用。
- **爬移补偿（可选）**：勾选「爬移补偿」后填写单张纸厚度（0.01～0.50 mm，0.01 mm 精度）与补偿上限（0～10 mm）；每帖独立按由外到内的纸张序号 k 计算 c = min(2 × 纸厚 × (k−1), 上限)，首张为 0；每张纸正反面共用同一 c，左版向右、右版向左（均朝折线）移动，纸张卡片上显示方向与毫米值。未启用或上限为 0 时，生成结果、校验与 CSV 均与未启用前完全一致。
- **CSV 导出**：
  - 单帖：纸张序号、面别、左版页码、右版页码；
  - 分帖：帖号、帖内纸张序号、面别、左版页码、右版页码（均带 BOM，Excel 可直接打开）；
  - 启用爬移补偿时，每面追加「左版爬移补偿（mm)」「右版爬移补偿（mm)」两列带符号补偿值（左版 +c、右版 −c）。
- **双面打样下载**：校验通过后可下载独立 HTML（无需服务端即可打开打印）。
  - 固定 **A4 横向**，每张纸**正反各一页**，依帖号、帖内纸张顺序排列（每张纸正面页后紧跟背面页）；
  - 每面标出左右页码、空白版位、中央折线（红色虚线）与四角对位标（十字套圆，正背面透光应重合）；
  - 按**短边翻转**双面打印设计：背面页左右版位相对正面**镜像排布**（左半 = 反面右版、右半 = 反面左版，即同一物理半区的正背面页码在打样页同一侧），文字保持正向；
  - 启用爬移补偿时，**仅页码内容**按该纸张补偿毫米值朝折线平移（左半 +c、右半 −c），对位标与折线保持原位。

## 生成修复方案

1. 生成拼版后，通过交换 / 编辑把版位改乱（校验结果会实时报错，导出按钮被禁用）。
2. 点击「生成修复方案」：右侧「修复方案」面板列出按顺序执行的步骤（先交换、后改值），每步标明版位、原值与目标值；当前拼版本就合法时提示「无需修复」。
3. 点击「一键应用」：服务端核对状态指纹后按方案修复，拼版恢复为标准拼版并通过校验，可继续导出 CSV / 下载打样；点击「放弃方案」可丢弃当前方案。
4. 若生成方案后又交换 / 编辑了拼版，方案会标记为失效，「一键应用」被拒绝并提示重新生成——重新点击「生成修复方案」即可。

## 双面打样打印方法

1. 校验通过后点击「下载打样」，浏览器会保存 `imposition-proof-*.html`（独立文件，双击即可用浏览器打开）。
2. 打开浏览器打印对话框（Chrome / Edge：Ctrl/Cmd + P）：
   - 纸张 **A4**、方向**横向**（文件已通过 `@page` 固定，通常无需手动选择）；
   - 缩放选 **100%（实际大小）**，**不要**选「适合页面」，否则折线与对位标位置会偏移；
   - 边距选「无 / 默认」均可（打样页为零边距满版布局）；
   - 双面打印选择**短边翻转**；单面打印机可只打印正面、手动按短边翻纸后再打背面。
3. 打印检查：将同一纸张的正背两面对齐，四角对位标与中央折线应重合；同一半区正反两面的页码应为连续页（同一张书叶）。

## 拼版规则

### 单帖

总页数 N（4 的倍数），共 N/4 张纸。第 i 张纸（1 起，最外层为第 1 张）：

| 面别 | 左版 | 右版 |
| ---- | ---------- | ---------- |
| 正面 | N − 2(i−1) | 2i − 1 |
| 反面 | 2i | N − 2i + 1 |

例如 8 页成品：第 1 张 正面[8, 1] / 反面[2, 7]，第 2 张 正面[6, 3] / 反面[4, 5]。

### 分帖

设置每帖最多纸张数 M（1～8），每帖容量 C = 4M。成品页 1..P 按顺序切为长度不超过 C 的连续区间：

- 除最后一帖外，每帖恰好取 C 个成品页（C 已是 4 的倍数，无需补白）；
- 最后一帖取剩余 r 个成品页，补齐到 ⌈r/4⌉×4 个版位，多出的 4−(r mod 4) 个版位为空白；
- 每帖内部独立套用上方骑马钉公式（帖内局部页码映射为全局页码，全局页码 = 帖起始页 − 1 + 帖内页码）。

例如 10 页、M=2（C=8）：第 1 帖 1～8 页（2 张纸：正面[8,1]/反面[2,7]、正面[6,3]/反面[4,5]）；第 2 帖 9～10 页（1 张纸：正面[空白,9]/反面[10,空白]）。

### 爬移补偿（可选）

骑马钉装订时，内层纸张的书口会相对外层向外“爬移”，需要把内层页面的内容朝折线方向预移补偿。生成前可填写：

| 输入 | 范围 | 说明 |
| ---- | ---- | ---- |
| 单张纸厚度 t | 0.01～0.50 mm（0.01 mm 精度） | 一张纸（4 个成品页）的厚度 |
| 补偿上限 cap | 0～10 mm（0.01 mm 精度） | 单张纸补偿量的最大值；0 表示不补偿，等同未启用 |

每帖独立按由外到内的纸张序号 k（1 起）计算该张纸的补偿量：

```
c = min(2 × t × (k − 1), cap)    （首张 k = 1 时 c = 0）
```

每张纸的正反两面使用同一个 c：**左版向右移动 c（+c）、右版向左移动 c（−c），均朝折线方向**。纸张卡片上显示该张纸的补偿方向与毫米值；CSV 每面追加左右版带符号补偿列；校验 / 导出时服务端按参数重算每张纸的补偿值，与提交的补偿数据不符（篡改）即拒绝。

计算示例：纸厚 0.10 mm、上限 2 mm 时，第 1～5 张纸的 c 依次为 0、0.20、0.40、0.60、0.80 mm；若上限改为 0.30 mm，则为 0、0.20、0.30、0.30、0.30 mm（被上限截断）。分帖模式下每帖重新从第 1 张（c = 0）起算。

## API

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| POST | `/api/generate` | 入参 `{ "pages": 6 }` 返回单帖标准拼版；入参 `{ "pages": 10, "sheetsPerSignature": 2 }` 返回分帖拼版（`sheetsPerSignature` 为 1～8 整数）；可选 `"creep": { "thickness": 0.1, "cap": 2 }` 启用爬移补偿（`thickness` 0.01～0.50 mm、`cap` 0～10 mm，`cap` 为 0 等同未启用） |
| POST | `/api/validate` | 入参为拼版状态（单帖或分帖结构均可），返回 `{ valid, errors, slotErrors }`；启用爬移补偿时按参数重算每张纸的补偿值，与提交数据不符（篡改）返回 400 |
| POST | `/api/repair/plan` | 入参为拼版状态，返回 `{ valid, stepCount, steps, fingerprint }`：`steps` 为按顺序执行的修复步骤（`swap` 交换 / `set` 改值，每步以 `changes` 列出版位、原值 `from`、目标值 `to`），`fingerprint` 为当前状态指纹；结构非法返回 400 |
| POST | `/api/repair/apply` | 入参 `{ state, fingerprint }`，指纹与当前状态不符（生成方案后拼版又被改动）返回 409；成功返回 `{ state, validation, steps }`，`state` 为修复后的完整状态（保留分帖结构与爬移参数，已通过校验） |
| POST | `/api/export` | 校验通过返回 CSV 文件；存在错误或补偿数据被篡改返回 400 |
| POST | `/api/export/proof` | 校验通过返回双面打样独立 HTML（`Content-Disposition` 附件，A4 横向）；存在错误返回 400 |
| GET | `/api/health` | 健康检查 |

版位内容：页码（整数）或 `null`（空白）。

分帖模式响应结构：

```json
{
  "pages": 10,
  "totalPages": 12,
  "sheetCount": 3,
  "signatureCount": 2,
  "sheetsPerSignature": 2,
  "signatures": [
    {
      "sig": 1,
      "sheetCount": 2,
      "startPage": 1,
      "endPage": 8,
      "sheets": [
        { "sig": 1, "index": 1, "front": { "left": 8, "right": 1 }, "back": { "left": 2, "right": 7 } }
      ]
    }
  ]
}
```

单帖模式的请求与响应保持原有格式（`{ pages, totalPages, sheetCount, sheets }`，纸张不带 `sig` 字段），旧客户端无需改动。校验返回中：分帖模式额外含 `errors.crossSignature`，且 `slotErrors` / `errors.pairing` 的条目带 `sig` 帖号；单帖模式不含这些字段。

启用爬移补偿时，响应顶层额外带 `creep: { thickness, cap }`，每张纸额外带 `creep` 字段（该张纸的补偿量 mm，按帖内由外到内序号 k 计算，每帖独立）；未启用或上限为 0 时不含这些字段，响应与旧版完全一致。

## CSV 格式

单帖：

```csv
纸张序号,面别,左版页码,右版页码
1,正面,空白,1
1,反面,2,空白
2,正面,6,3
2,反面,4,5
```

分帖（新增帖号与帖内纸张序号）：

```csv
帖号,帖内纸张序号,面别,左版页码,右版页码
1,1,正面,8,1
1,1,反面,2,7
2,1,正面,空白,9
2,1,反面,10,空白
```

启用爬移补偿时，每面追加左右版带符号补偿列（左版 +c 向右、右版 −c 向左，均朝折线；首张 c 为 0）。以 8 页、纸厚 0.10 mm、上限 2 mm 为例：

```csv
纸张序号,面别,左版页码,右版页码,左版爬移补偿(mm),右版爬移补偿(mm)
1,正面,8,1,+0.00,+0.00
1,反面,2,7,+0.00,+0.00
2,正面,6,3,+0.20,-0.20
2,反面,4,5,+0.20,-0.20
```
